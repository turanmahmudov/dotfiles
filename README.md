# Dotfiles

My personal dotfiles managed with [YADM](https://yadm.io/).

Tested on Ubuntu 25.10 and Ubuntu 25.04.

## Installation

```bash
yadm clone <your-repo-url>
yadm config local.class work  # or personal
yadm config yadm.alt-copy true
yadm alt
yadm bootstrap
```

## Important Keybindings

- `SUPER + Return` - Terminal
- `SUPER + T` - Terminal with tmux
- `SUPER + Space/D` - Application launcher
